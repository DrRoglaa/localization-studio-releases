# Support independent development

[← Back to README](README.md)

Hello! I'm **David Rok Roglič**, the solo indie developer behind Localization Studio.

I'm building this application independently, with a focus on dependable `.xcstrings` editing and useful Windows/Linux tooling. If you like the direction of the project, your support helps me prioritize testing, accessibility, documentation, and ongoing development.

## Ways to help today

- **Star this repository** to help other developers discover the project.
- **Share thoughtful feature requests** using the [feature request form](https://github.com/DrRoglaa/localization-studio-releases/issues/new?template=02-feature-request.yml).
- **Report reproducible problems** using the [bug report form](https://github.com/DrRoglaa/localization-studio-releases/issues/new?template=01-bug-report.yml) once a testable build is available.
- **Spread the word** to developers who work with application localization.

## Monetary donations

**A donation/payment option is not configured yet.** I will add a verified donation link here if I decide to enable direct financial support. Please do not send money to unofficial accounts claiming to represent Localization Studio.

Donations, if offered in the future, will be voluntary and will not imply a guaranteed feature, delivery deadline, support entitlement, or product license.
